# موقع وسيم (نسخة التطبيق)

كل الملفات في مستوى واحد بلا مجلدات، لتُرفع من الجوال دفعة واحدة.

ارفعها كلها إلى جذر المستودع المنشور (المستودع الذي يظهر رابطه في Settings ← Pages):
index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png
(واختيارياً: 404.html, robots.txt, sitemap.xml)

بعد الرفع افتح الرابط في نافذة تصفح خاص. لتثبيت التطبيق: من Chrome على أندرويد يظهر شريط "تثبيت التطبيق"، ومن Safari على آيفون: مشاركة ← إضافة إلى الشاشة الرئيسية.
